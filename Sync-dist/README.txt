Sync for macOS
==============
Run: bash install.sh
Requires macOS 12+ and Python 3. The installer asks for your account credentials,
creates a private local configuration and Python environment, and schedules Sync
at 03:00 local time. Installation does not upload images.

Sync uploads images from Photos, common folders, iCloud Drive, Messages and chat
folders to your configured server. Server-side filtering happens after upload.
See the repository README.md for permissions, download instructions, and usage.

Uninstall: bash uninstall.sh
